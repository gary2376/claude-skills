# dating-profile-checker

繁體中文交友軟體自介健檢 Claude Skill，依平台（Tinder/Bumble/Hinge）跟目標（快速配對/認真找對象）給對應建議，不套用單一套「越具體越好」的通用公式。

## 安裝

在終端機執行（或直接貼給你的 agent 執行）：
```
npx skills add https://github.com/gary2376/claude-skills/tree/master/dating-profile-checker
```
會自動偵測目前的 agent（Claude Code、Codex、Cursor 等）裝到對應路徑，不限 Claude 專用。

## 功能
- 空話形容詞偵測（熱愛生活、個性隨和等，建議精簡）
- 籠統但真實的興趣清單辨識（旅行、美食、電影等，建議保留並提示升級，不會被誤刪）
- 純身份標籤型自介偵測（只有年齡/職業，反問要素材，不會幫你捏造內容）
- 依平台 + 目標給長度與策略建議，附研究依據

## 使用

裝好後直接在 Claude 對話貼自介文字，說明想投的平台跟目標（例如「這是我的 Tinder 自介，想認真找對象」）。Skill 預設只會給診斷跟反問，不會主動幫你代寫；想要潤飾版本，補充細節後再明確說「幫我潤一下」即可。

## 範例

**輸入**
平台：Tinder，目標：快速多配對
自介：「熱愛生活，喜歡旅行、美食、看電影，個性隨和開朗，希望遇到聊得來的人。」

**輸出（節錄）**
> ⚠️ 空話形容詞（建議精簡）：「熱愛生活」「個性隨和開朗」「希望遇到聊得來的人」——拿掉主詞放誰身上都成立，沒有資訊量。
> 📌 籠統但真實的內容（保留，不刪）：「喜歡旅行、美食、看電影」——這是你實際提供的資訊，只是停在類別層級，有沒有想到哪一項的具體例子？
> 📏 長度：目前字數落在 Tinder 快速配對的合理範圍，但內容偏空泛。

依據：SwipeStats 獨立分析 7,079 筆真實檔案——具體內容比空泛長句更能提升配對品質。
