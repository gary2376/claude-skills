# prompt-craft

把「幫我寫封信」這種模糊需求，轉成 AI 聽得懂的結構化 prompt。不是單向轉換工具——會先反問你漏講了什麼，
不會自己亂猜。

## 安裝

在終端機執行（或直接貼給你的 agent 執行）：
```
npx skills add https://github.com/gary2376/claude-skills/tree/master/prompt-craft
```
會自動偵測目前的 agent（Claude Code、Codex、Cursor 等）裝到對應路徑，不限 Claude 專用。

## 功能
- 偵測需求裡缺了角色、背景、格式、受眾語氣、範例、限制這 6 個維度中的哪些
- 主動反問缺漏的部分，不會直接臆測（除非你說「不用問了直接猜」）
- 在 Claude Code 這類有原生互動選單的環境下，反問會用可勾選/可輸入的選單呈現；沒有這個功能的
  環境（Claude Desktop、網頁版）會退回純文字提問，效果一樣，只是介面不同
- 每補一個欄位附一句「為什麼要補這個」，附權威來源依據
- 職場書信、會議紀錄、資料分析需求、客服回覆 4 個場景有在地化優先序

## 使用

裝好後直接貼你想請 AI 做的模糊需求，或問「這個 prompt 要怎麼寫比較好」。

## 範例

**輸入**
「幫我寫封信跟主管請假」

**輸出（節錄）**
> 這句話缺了幾個關鍵資訊，我先問清楚：想請幾天假、什麼原因（不用太細）、希望用什麼語氣（正式 or 平常口吻就好）？
>
> 使用者補充後 → 組出結構化 prompt：角色（你本人）、背景（請假原因）、格式（一封簡短信）、受眾語氣（給主管，正式但不生硬），附一句「為什麼要補語氣這個欄位」的說明。
