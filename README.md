# claude-skills

自建 Claude Skills 庫，每個資料夾一個獨立可安裝的 skill。

## 收錄

- [resume-jd-checker](resume-jd-checker/) — 繁體中文履歷 x JD 關鍵字健檢
- [prompt-craft](prompt-craft/) — 模糊需求轉結構化 prompt，缺漏欄位主動反問

## 安裝

貼給 Claude（`<skill資料夾名>` 換成上面清單的名字）：
```
幫我安裝這個 Claude Skill：https://github.com/gary2376/claude-skills/tree/master/<skill資料夾名>
複製到 ~/.claude/skills/<skill資料夾名>
```
